# Research Protocol: Memory in Cognitive Psychology

## Purpose

This protocol supports empirical and simulated research on memory as a dynamic system for encoding, retaining, consolidating, reconstructing, and retrieving information across time.

## Core constructs

- **Memory system:** sensory, working, episodic, semantic, procedural, implicit, explicit, source memory.
- **Encoding depth:** shallow, phonological, semantic, elaborative, self-referential, or generation-based processing.
- **Study type:** restudy, retrieval practice, spaced practice, massed practice, elaboration, interleaving, generation, misinformation, or AI-supported retrieval.
- **Delay:** retention interval between learning and test.
- **Retention strength:** estimated accessibility of the memory trace.
- **Cue quality:** match between retrieval cue and encoded trace.
- **Interference:** competition from related memories, prior learning, later learning, or semantically similar materials.
- **Consolidation support:** sleep, rest, repeated exposure, or reduced interference.
- **Source context:** contextual information about where, when, how, or from whom information was learned.
- **Misinformation exposure:** post-event information that may alter later recollection.
- **Confidence:** subjective certainty in memory judgment.
- **Signal detection:** sensitivity and response bias in recognition memory.
- **Learning transfer:** ability to use remembered material in a related task.

## Recommended study designs

1. Free recall after multiple retention intervals.
2. Recognition memory with old/new responses and signal detection.
3. Retrieval practice versus restudy.
4. Spacing versus massed practice.
5. Levels-of-processing manipulation.
6. Source-monitoring experiment.
7. Misinformation/post-event suggestion experiment.
8. Proactive and retroactive interference design.
9. Sleep/consolidation or delayed-retention design.
10. Human-AI memory support study measuring recall, recognition, transfer, and source confusion.

## Measurement cautions

Separate storage failure from retrieval failure where possible. Measure cue quality, interference, source memory, confidence, and response time. Analyze hits, false alarms, d-prime, and criterion for recognition tasks. Model participant and item effects. In AI-supported memory tasks, distinguish useful retrieval scaffolding from source confusion or automation-induced confidence.
