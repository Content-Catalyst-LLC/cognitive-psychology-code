# Research Protocol: Perception in Cognitive Psychology

## Purpose

This protocol supports empirical and simulated research on perception as an active process of sensory registration, organization, inference, prediction, recognition, and action guidance. It is intended for psychophysical experiments, signal-detection tasks, visual search, perceptual-learning paradigms, multisensory integration studies, noisy recognition tasks, interface-salience experiments, human factors, medical image perception, and human-AI perception-support studies.

## Core constructs

### Modality

Records sensory channel: visual, auditory, tactile, multisensory, proprioceptive, interoceptive, or interface.

### Stimulus level

Quantifies stimulus intensity, contrast, coherence, clarity, frequency, amplitude, luminance, signal strength, or other experimental manipulation.

### Signal present

Indicates whether the signal or target is present.

### Response yes

Indicates whether the participant judged that the signal or target was present.

### Sensory evidence

Models the strength of incoming sensory evidence.

### Prior expectation

Measures expectation, learned base rate, task probability, cue-induced prior, or context-driven hypothesis strength.

### Cue quality

Measures how diagnostic the cue is for the relevant perceptual interpretation.

### Attention gain

Measures attentional prioritization of the stimulus, location, feature, modality, or task goal.

### Context strength

Measures contextual support for a perceptual interpretation.

### Noise level

Measures sensory or environmental uncertainty.

### Prediction error

Measures mismatch between incoming sensory input and predicted input.

### Multisensory congruence

Measures whether input from multiple modalities supports a common interpretation.

### Visual-search set size

Records the number of objects or distractors in a visual search display.

### Distractor similarity

Measures how similar distractors are to the target.

### Interface salience

Measures visual or interaction-design salience in an interface task.

## Recommended study designs

1. Two-alternative forced-choice discrimination task.
2. Yes/no signal-detection task.
3. Contrast or intensity psychometric function.
4. Visual search with set-size manipulation.
5. Feature integration or conjunction search task.
6. Cueing experiment manipulating attention gain.
7. Ambiguous figure task manipulating prior expectation.
8. Multisensory congruence experiment.
9. Perceptual-learning experiment across repeated blocks.
10. Human-AI or interface experiment measuring salience, uncertainty, attention, and error detection.

## Measurement cautions

- Distinguish sensitivity from response bias.
- Use signal detection metrics for yes/no recognition tasks.
- Model participant-level and stimulus-level effects.
- Separate sensory evidence from prior expectation.
- Record response time and confidence, not only accuracy.
- Avoid treating perception as a passive copy of stimulus input.
- In HCI contexts, separate perceptual salience from task usefulness.
- In AI-supported perception tasks, distinguish assistance from overreliance and false confidence.

## Ethical and institutional considerations

Perception affects safety, diagnosis, law, accessibility, interface design, and automation. Systems that bury important signals, make uncertainty invisible, or privilege one perceptual ability profile over another can create unequal risk. Responsible perceptual design should support accessibility, reduce unnecessary ambiguity, preserve uncertainty, and make critical signals visible without inducing overload.
