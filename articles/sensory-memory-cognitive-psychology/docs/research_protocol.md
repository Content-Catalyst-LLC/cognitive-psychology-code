# Research Protocol: Sensory Memory in Cognitive Psychology

## Purpose

This protocol supports empirical and simulated research on sensory memory as brief modality-specific persistence after stimulus offset. It is intended for partial-report experiments, iconic-memory tasks, echoic-memory tasks, haptic-memory tasks, cue-delay studies, masking studies, sensory trace decay models, attention-selection studies, and human factors or HCI experiments where early perceptual persistence matters.

## Core constructs

### Modality

Modality identifies the sensory register involved: visual/iconic, auditory/echoic, tactile/haptic, or multimodal.

### Cue delay

Cue delay measures the time between stimulus offset and the report cue. It is central to estimating decay of sensory traces.

### Stimulus duration

Stimulus duration records how long the input was available before offset.

### Array size

Array size records the number of items presented, especially in visual partial-report paradigms.

### Mask condition

Mask condition records whether a visual, auditory, or tactile mask disrupted sensory persistence.

### Cue validity

Cue validity measures whether the cue correctly indicates the subset or location to report.

### Trace strength

Trace strength estimates the surviving sensory representation at the time of selection.

### Salience

Salience measures bottom-up stimulus priority.

### Attentional priority

Attentional priority measures top-down or task-driven selection priority.

### Report score

Report score measures how much information was correctly reported.

### Correct report

Correct report is a binary trial-level report accuracy indicator.

### Partial-report advantage

Partial-report advantage compares cued report with whole report under brief exposure.

### Working-memory transfer

Working-memory transfer measures whether selected sensory information was stabilized for later processing.

## Recommended study designs

1. Visual partial-report task inspired by Sperling.
2. Auditory partial-report task inspired by Darwin, Turvey, and Crowder.
3. Tactile or haptic change-detection task.
4. Cue-delay manipulation across modality.
5. Masking experiment comparing no-mask, early-mask, and late-mask conditions.
6. Attention manipulation comparing valid, invalid, and neutral cues.
7. Human factors display study testing whether brief visual cues support or overload selection.
8. HCI notification study comparing auditory, visual, and haptic alerts.
9. Multimodal sensory persistence study comparing modality-specific decay functions.

## Measurement cautions

- Distinguish sensory persistence from working memory.
- Do not infer conscious access from trace availability alone.
- Separate whole-report limitations from partial-report availability.
- Model participant and stimulus effects.
- Treat cue delay as continuous when possible.
- Use modality-specific timing windows.
- Check whether masking effects reflect sensory disruption, attention, or response interference.
- Avoid treating sensory memory as a single centralized store.

## Ethical and institutional considerations

Sensory memory research can inform safety, accessibility, interface design, warning systems, and assistive technologies. Researchers should consider differences in hearing, vision, touch, aging, neurodivergence, disability, fatigue, and environmental stress. Interfaces should not assume uniform sensory persistence or attentional availability across users.
