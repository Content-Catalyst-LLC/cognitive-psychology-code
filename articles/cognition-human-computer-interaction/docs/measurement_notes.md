# Measurement Notes

## Total interaction cost

A simple research index can be constructed as:

C_total = C_p + C_a + C_m + C_d

where:

- C_p = perceptual cost
- C_a = attentional cost
- C_m = memory cost
- C_d = decision cost

A broader usability-risk score can include errors, trust miscalibration, and accessibility friction:

U_risk = w_l L + w_e E + w_t T_m + w_f F - w_a A

where:

- L = cognitive load
- E = normalized error count
- T_m = trust miscalibration
- F = accessibility friction
- A = mental-model alignment

## Recommended reliability checks

- Internal consistency for workload or trust scales
- Inter-rater agreement for error coding
- Test-retest stability for repeated task families
- Participant-level random effects for repeated observations
- Sensitivity analysis for composite index weights

## Recommended validity checks

- Convergent validity with response time and error count
- Predictive validity for task success and abandonment
- Discriminant validity between satisfaction and comprehension
- Ecological validity in realistic workflows
- Accessibility validity across heterogeneous users

## Interpretation cautions

- A system can be efficient for expert users and hostile to novices.
- A system can reduce visible effort while increasing hidden cognitive burden.
- A system can feel intuitive because it exploits harmful defaults.
- A system can be attractive while remaining cognitively misaligned.
