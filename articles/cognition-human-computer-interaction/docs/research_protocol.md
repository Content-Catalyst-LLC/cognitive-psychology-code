# Research Protocol: Cognition in Human-Computer Interaction

## Purpose

This protocol supports empirical and simulated research on how cognitive processes shape interaction with digital systems. It is intended for cognitive psychologists, HCI researchers, human factors specialists, usability researchers, accessibility researchers, UX researchers, and AI-interface researchers.

## Core constructs

### Interface condition

Interface condition refers to the design variant, workflow, system state, or experimental interface being evaluated. Examples include baseline, cluttered, guided, adaptive, accessible, or AI-assisted interfaces.

### Perceptual load

Perceptual load measures the visual or sensory effort required to detect and interpret task-relevant information.

### Attentional demand

Attentional demand measures the degree to which the interface divides or competes for user attention.

### Working-memory load

Working-memory load measures the amount of task state, procedural information, or context users must maintain while interacting.

### Task difficulty

Task difficulty captures objective or rated complexity of the task.

### Mental-model alignment

Mental-model alignment measures the match between the user's understanding of system structure and the system's actual behavior.

### Cognitive load

Cognitive load can be measured through subjective ratings, secondary-task performance, response latency, eye-tracking metrics, physiological indicators, or composite workload scales.

### Success

Success indicates whether the user completed the task correctly or reached the intended goal state.

### Error count

Error count measures incorrect clicks, invalid entries, navigation failures, wrong selections, ignored warnings, or recovery actions.

### Trust and automation reliance

Trust and automation reliance measure how users depend on system recommendations, AI assistance, defaults, or automated workflows.

## Recommended study designs

1. Controlled interface comparison with randomized design conditions.
2. Usability experiment with repeated tasks and participant-level random effects.
3. Cognitive-load manipulation study.
4. Accessibility evaluation across perceptual, motor, and cognitive constraints.
5. Human-AI interaction experiment measuring trust and override behavior.
6. Field study combining interaction logs, interviews, and performance outcomes.

## Measurement cautions

- Do not treat fast completion as always better.
- Separate efficiency from comprehension.
- Separate trust from appropriate reliance.
- Preserve error types rather than only total error counts.
- Model participant, task, and interface effects where possible.
- Evaluate whether the interface hides cognitive work rather than reducing it.
- Include accessibility and unequal user burden in the research design.

## Ethical and institutional considerations

HCI systems increasingly mediate access to work, education, healthcare, public services, finance, and civic participation. Researchers should evaluate not only average usability, but also who is burdened, excluded, confused, interrupted, or made vulnerable by interface design.
