# Outputs

Generated outputs should be written here.

Expected examples:

- `summary_by_condition.csv`
- `learning_curve_by_session.csv`
- `model_summary.txt`
- `comprehension_model_coefficients.csv`
- `r_model_summaries.txt`
- `r_learning_curve_accuracy.png`
- `cpp_retrieval_transfer.csv`
- `julia_encoding_transfer.csv`

Generated output files may be committed if they are small and useful for documentation, or ignored if they are large simulation artifacts.
