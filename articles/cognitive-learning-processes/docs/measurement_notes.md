# Measurement Notes

## Learning update

K_{t+1} = K_t + alpha * f(X_t, K_t)

where K_t is the knowledge state, X_t is new input, and f is the integration function relating new information to existing knowledge.

## Working-memory constraint

sum(a_i) <= C

where a_i are resource demands and C is available working-memory capacity.

## Transfer relation

T_{A->B} proportional to K_A * S(A,B)

where K_A is knowledge learned in context A and S(A,B) is structural overlap with context B.

## Learning gain

learning_gain = posttest_score - pretest_score

## Retention loss

retention_loss = posttest_score - delayed_retention_score

## Recommended reliability checks

- Internal consistency for multi-item comprehension or transfer scales
- Split-half reliability for test forms
- Inter-rater reliability for explanations or open responses
- Test-retest reliability for delayed retention
- Participant-level random effects for repeated measurements
- Task-level random effects for item difficulty

## Recommended validity checks

- Convergent validity with accuracy, recall, explanation quality, and transfer
- Predictive validity for later retention or application
- Discriminant validity between familiarity and durable learning
- Ecological validity in classroom, workplace, interface, and AI-supported learning contexts
