# Research Protocol: Semantic Memory in Cognitive Psychology

## Purpose

This protocol supports empirical and simulated research on semantic memory as the long-term knowledge system that organizes concepts, facts, meanings, categories, features, schemas, and relations. It is intended for cognitive psychologists, psycholinguists, memory researchers, cognitive neuroscientists, learning scientists, AI researchers, and knowledge-engineering researchers.

## Core constructs

### Semantic distance

Semantic distance measures how far two concepts are from one another in a network, feature space, embedding space, hierarchy, or rated semantic field.

### Category typicality

Category typicality measures how representative an item is of its category. A robin is typically judged a more typical bird than an ostrich, even though both are birds.

### Feature overlap

Feature overlap measures the extent to which two concepts share properties, attributes, functions, affordances, or perceptual/functional features.

### Associative strength

Associative strength measures how strongly one concept cues another through experience, language, co-occurrence, or learned relations.

### Fact verification

Fact verification tasks measure whether participants can judge semantic propositions such as "a canary is a bird" or "a hammer is a tool."

### Retrieval latency

Retrieval latency measures the time required to access or verify semantic information. It is often interpreted as reflecting retrieval cost, distance, familiarity, or task difficulty.

### Schema consistency

Schema consistency measures whether a proposition or concept fits with an existing organized knowledge structure.

### False semantic association

False semantic association records incorrect acceptance of semantically related but false statements, which can reveal the pull of association over truth.

## Recommended study designs

1. Semantic fact-verification experiment with true and false propositions.
2. Category-typicality study comparing central and peripheral category members.
3. Semantic-distance study using network distance, feature distance, or embedding distance.
4. Priming experiment measuring facilitation from related cues.
5. Semantic association study comparing taxonomic and thematic relations.
6. Neuropsychological or cognitive-neuroscience study comparing modality-specific and transmodal semantic effects.
7. Human-AI comparison of semantic retrieval, embedding similarity, and verification behavior.

## Measurement cautions

- Do not equate association strength with semantic truth.
- Separate category membership from category typicality.
- Separate semantic distance from response difficulty.
- Track false positives on related but false propositions.
- Model participant and item effects because words, facts, and categories vary greatly in familiarity.
- Distinguish semantic memory from episodic retrieval when task instructions or stimuli permit autobiographical recall.

## Ethical and institutional considerations

Semantic memory research is also relevant to education, search systems, language technologies, cultural knowledge, and knowledge representation. Researchers should avoid treating semantic structures as universal when they may reflect language, culture, education, social power, and unequal access to knowledge.
