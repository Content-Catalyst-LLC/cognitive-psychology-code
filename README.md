# Cognitive Psychology Code

Open computational scaffolding for the Cognitive Psychology knowledge series.

This repository supports article-level examples for attention, perception, memory, working memory, decision making, heuristics, cognitive bias, risk perception, cognitive load, learning, metacognition, language processing, concept formation, semantic memory, problem solving, analogical reasoning, insight, human-computer interaction, artificial intelligence, and organizational decision making.

## Structure

Each article folder contains:

- `python/`
- `r/`
- `julia/`
- `cpp/`
- `fortran/`
- `c/`
- `rust/`
- `go/`
- `sql/`
- `notebooks/`
- `docs/`
- `data/raw/`
- `data/processed/`
- `outputs/`
